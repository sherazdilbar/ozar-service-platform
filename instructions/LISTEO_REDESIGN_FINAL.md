## 🎨 Design System

### Core Components
- **ProLayout** - Wrapper with Header, Sidebar, Content, Footer
- **ProSidebar** - Fixed left navigation with all menu items
- **Page-listeo variants** - Clean redesigns for each page

### Design Principles
✅ White cards with subtle borders (`border-gray-200`)
✅ Minimal shadows (`shadow-sm`)
✅ Teal accent color (`#0d9488`)
✅ Clean typography (bold headers, regular body)
✅ Professional spacing (`p-6`, `gap-6`, `mb-8`)
✅ No heavy gradients
✅ Simple, scannable layouts
✅ Mobile responsive (sidebar hidden on mobile)
✅ Dark mode support throughout

### Color Palette
- **Primary**: Teal-600 (#0d9488)
- **Background**: White / Gray-50
- **Borders**: Gray-200 / Gray-700
- **Text**: Gray-900 / White
- **Hover**: Gray-50 / Gray-700
- **Success**: Green-600
- **Warning**: Yellow-500
- **Error**: Red-600

### Typography
- **Headers**: text-3xl font-bold
- **Subheaders**: text-xl font-bold
- **Body**: text-base
- **Labels**: text-sm font-semibold
- **Captions**: text-xs text-gray-500

### Spacing
- **Page padding**: p-6 lg:p-8
- **Card padding**: p-6
- **Section margins**: mb-8
- **Form gaps**: gap-6
- **Table cells**: px-6 py-4
